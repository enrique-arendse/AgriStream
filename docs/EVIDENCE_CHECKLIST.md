# Evidence checklist — replace placeholders with genuine evidence
1. Azure resource group and resources overview.
2. App Service overview and live deployed home/login page.
3. Azure SQL database overview, `Users` and `DeviceRegistry` tables, and successful MVC SQL connection.
4. Storage account overview; Blob container with uploaded image; Table Storage `ProcessingAudit` and `FarmTelemetry`; Queue Storage.
5. Function App overview showing all four function names and successful invocation/monitor logs.
6. End-to-end Blob upload followed by audit entity.
7. Dashboard displaying telemetry.
8. Irrigation POST accepted, queue trigger execution and SQL registry update.
9. JMeter/Azure Load Testing configuration and summary: virtual users, duration, total requests, throughput, average and percentile latency, errors.
10. Application Insights/Monitor charts for requests, failures, response time, CPU/memory and dependencies.
11. Autoscale configuration rules and scale history showing instance count before/during/after test.
12. GitHub repository URL and App Service public URL.
Do not fabricate or edit evidence to imply a test ran when it did not.
